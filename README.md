# حاضر — نظام الحضور والغياب

تطبيق ويب عربي لإدارة الحضور والغياب، مع دعم QR والتقارير.

## النشر على GitHub Pages

1. أنشئ مستودعًا جديدًا على GitHub، مثل `hader-attendance`.
2. ارفع جميع الملفات والمجلدات الموجودة في هذا المشروع، مع الحفاظ على مجلد `assets`.
3. من المستودع افتح **Settings → Pages**.
4. تحت **Build and deployment** اختر **Deploy from a branch**.
5. اختر الفرع `main` والمجلد `/(root)` ثم اضغط **Save**.
6. انتظر حتى يظهر رابط الموقع في صفحة Pages.

## ملاحظة مهمة عن البيانات

من دون إعداد Firebase، يعمل التطبيق في وضع التخزين المحلي؛ البيانات محفوظة في المتصفح والجهاز نفسه، ولن تتم مزامنتها تلقائيًا بين الأجهزة. إذا أردت تسجيل دخول ومزامنة سحابية، أعد إعداد Firebase Authentication وCloud Firestore، ثم ضع إعدادات الواجهة في `assets/firebase-config.js` واضبط قواعد Firestore بشكل آمن قبل استخدام بيانات حقيقية.

## الملفات

- `index.html`: صفحة التطبيق الرئيسية.
- `assets/app.js`: منطق التطبيق.
- `assets/cloud.js`: التكامل السحابي.
- `assets/i18n.js`: النصوص والترجمة.
- `assets/style.css`: التنسيق.
- `assets/firebase-config.js`: ملف إعداد Firebase (فارغ افتراضيًا).
